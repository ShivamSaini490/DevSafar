Frontend architectural prompt :
------------------------------

Build the frontend for an Agentic AI Travel Planner using React, TypeScript, Vite, Tailwind CSS, shadcn/ui, Lucide React, React Router, Zustand, TanStack Query and Recharts.

Follow the attached frontend architecture diagram and folder structure.

Implement 7 screens/views: Sign In, Sign Up, Forgot/Reset Password, Main Chat with left sidebar and 7-day chat history, Trip Results with rich interactive cards/maps/charts, Profile/Settings, and Temporary Chat mode.

Design a premium, clean, responsive ChatGPT-inspired layout with travel-specific visualization. Temporary chats must be tab-scoped, never appear in history, and not be persisted to localStorage. Saved conversations belong to authenticated users and expire seven days after creation; backend enforces expiry. No share-chat feature. Guests may explore using temporary chats. Provide loading, empty, error and streaming states.

Create reusable components for budget donut charts, transport comparison charts, daily expenses, itinerary timeline, transport, hotels, attractions, map and AI chat. Use typed API service interfaces and mock adapters if backend is not ready; clearly label mock data. Do not invent live prices. Keep frontend API calls centralized, authentication cookie-safe, and never put secret API keys in the frontend. Produce runnable code, environment example, README, and concise module explanations. Implement in small testable steps.
